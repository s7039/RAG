## 四、Bad Case（已修复）

### 1. r03 张三九的 MRI 报告在哪一页（该拒答却硬答）→ 已修复

- **现象（修复前）**：返回 `五、健康风险评估`、`一、基本信息` 等无关片段，没有任何一条提到 MRI。
- **归因**：检索永远返回 Top-K，`_compose` 默认「有片段就有答案」；本地哈希向量对任何中文
  问题都会给出非零相似度，`score_threshold` 默认又是 0，库外问题在现有信号下无法区分。
- **修复**：在 `search_knowledge` 里加相关性门槛（[app/agent/tools.py](../app/agent/tools.py)）：
  去掉患者名后，把问题切成二字词/英文词，要求至少一个实词出现在 Top-4 片段里；
  一个都没有就返回「检索结果与问题不相关」，最终回答「没查到」。
- **验证**：r03 现在输出「没查到：检索结果与问题不相关…」；r01/r02 仍正确拒答，拒答 3/3。

### 2. s07 / m01 Top-1 被同词不同义片段抢走 → 已修复

- **现象（修复前）**：
  - s07 `李四六的空腹血糖是多少？` Top-1 是 `第4页 · 六、医生建议`，真正含 `5.2 毫摩尔/升`
    的 `第3页 · 四、体检与化验结果` 排第 2；
  - m01 `那他的饮食建议是什么` Top-1 是 `第1页 · 三、生活方式和习惯`，`第2页 · 六、医生建议` 排第 3。
- **归因**：BM25 只看词面，「空腹血糖」在「医生建议」里也出现且密度更高；本地哈希向量语义
  区分弱，融合后被关键词分数带偏。
- **修复**：在 `Retriever` 里加轻量规则 rerank（[app/rag/retriever.py](../app/rag/retriever.py)）：
  数值题（多少/是多少/什么时候…）给含「数值 + 临床单位/日期」的片段 +0.05；
  建议题（建议/怎么办/饮食…）给「医生建议」章节 +0.10。
- **验证**：s07 Top-1 变为 `第3页 · 四、体检与化验结果`（0.628 > 0.583）；m01 Top-1 变为
  `第2页 · 六、医生建议`（0.473 > 0.453）；Top-1 13/15 → 15/15。
- **说明**：这是规则 rerank，不是 cross-encoder 模型。真实 reranker（bge-reranker）和真实
  embedding 需要 API Key/模型文件，本机都没有，所以没有接；接口位置已经留在这里，
  换成模型时替换 `_answer_type_bonus` 即可。

### 3. s01 张三九对什么药物过敏（语料自相矛盾）→ 已修复

- **现象（修复前）**：回答同时给出「青霉素」和「头孢类」，两份档案都自称张三九。
- **归因**：`健康档案(含表格02).pdf` 整份是王五的数据，只有「姓名」字段写成张三九；
  `健康档案(含表格01).pdf` 的体检表也是王五的。切分器按姓名识别患者，把王五的记录挂到了
  张三九名下。
- **修复**：新增语料补丁 [app/rag/patient_overrides.py](../app/rag/patient_overrides.py)，在切分时按
  「文件 + 章节」覆盖患者：含表格02 全篇 → 王五；含表格01 的「二、体检与化验结果」→ 王五。
  重新灌库并同步 PostgreSQL。
- **验证**：重建索引后 `含表格02` 的 patient 全部是王五，`含表格01` 是张三九 + 王五；
  s01 的回答只剩「青霉素」，任务完成率 23/25 → 25/25。

## 五、语料质量问题（已修一部分，仍有遗留）

1. ~~跨患者污染~~：已通过 `patient_overrides.py` 修正标签；源 PDF 本身没改，换语料时删掉补丁即可。
2. **重复记录**：修正后 `含表格02` 与 `健康档案.pdf` 里的王五记录内容相同，同一事实有 3 份来源，
   Top-1 可能命中任一份（当前评测期望值都命中了主档案，但这是运气好，不是机制保证）。
   建议后续按「患者 + 章节 + 内容哈希」去重。
3. **同名指标多版本**：张三九空腹血糖在 `健康档案.pdf` 是 6.8，在含表格两份里是 5.5；
   身高 175 vs 180、BMI 25.5 vs 26.2。评测只选唯一出处，否则对错无法判定。
4. **无关语料**：`llama2.pdf` 占 27/58 chunk（47%），与健康档案无关；本次 15 条引用类用例
   没有被它挤进 Top-4，但它会稀释向量库、增加误召回概率，正式版应移出 `input/`。
